# US Trademark Applications by Class, Newest Listed

One recent US trademark application listed on a FoxAPIs class page. A mark filed in several classes can appear once per class.

| File | Rows (built 2026-11-27) |
|---|---|
| `trademark-filings-by-class-current.csv` | 4,935 |

**Browse it:** https://foxapis.com/trademarks/
Need one record on request, from code? [Brand record API](https://foxapis.com/api/brand-record/).

## Source and terms

US Patent and Trademark Office application data. Each row links to the USPTO's own status page. **An application is not a registration.**

## What this file is not

Each class page lists only its newest applications, from corporations and limited liability companies. Of the owner's address only the city is shown, as filed; no person, street or state. Removal requests are honored.

## Columns

| Column | Meaning |
|---|---|
| `filing_date` | Date filed |
| `class_number` | International class |
| `mark` | The mark, as filed |
| `owner_as_filed` | Owner name, as filed |
| `owner_city` | Owner city, as filed |
| `serial_number` | USPTO serial number |
| `uspto_status_url` | USPTO status page |
| `listed_on` | The FoxAPIs page the row came from |

## Refresh

Rebuilt weekly from the public pages. It holds only what those pages show; each file is a snapshot, and earlier
rows drop out as the pages change.
